# OpenDesk 0.3.0 正式版本更新内容

## 主要新增功能

相对于 0.2.0 版本，在 0.3.0 版本中我们正式支持了以下主要功能:

### 面向长程任务的一系列优化机制

- 实现多 Agent 框架和注册机制，子任务创建时按照任务类型自动匹配适合的 Agent；
- 内置 Explore 和 Plan Agent，重写 Plan Mode 以独立上下文完成代码仓探索和计划编制，降低整体上下文开销；
- 引入任务目标跟踪功能，通过 `/goal` 命令或桌面版"创建目标"使用，在任务执行过程中持续审计目标完成情况；
- 优化任务自纠错体系，包括工具调用修复，面向更多不同模型API行为的容错，检测任务异常中断并自动恢复等;
- 内置基于 Evidence Card 的上下文优化技术，节省约 80% 输入 Tokens, 在设置选项中可选开启;

### 内嵌浏览器控制

- 通过 `/use-browser` 在右侧工作空间面板嵌入任务级浏览器窗口，不依赖系统浏览器；支持画中画模式在面板收起时持续查看页面状态，与系统浏览器不共享登录状态以减少凭证暴露风险；
- 内置浏览器应用，支持本地收藏夹管理、历史记录管理等基本功能；支持导入根证书和自定义 User-Agent；
- BrowserUse 能力持续优化：生成无障碍树时跳过不可见元素，支持跨域 iframe 的快照与点击操作，操作后立即快照将两步合一以大幅提升操控速度；

### 智能文件系统与记忆

- 启用智能文件系统，支持将本机任意目录纳入管理，对文件内容进行向量化和分块索引，对话涉及本地知识时自动查找相应文件并基于文件回答问题；
- 启用记忆功能，支持个人用户画像、工作区记忆和全局事实记忆，可在左下角记忆面板中管理；

### 任务自动化

- 新增任务自动化应用，支持周期任务、定时任务、按需触发任务的图形化创建，内置常见任务模板降低使用门槛；
- 自动化任务支持配置消息渠道（如微信/飞书），PC 上配置的定时任务也可推送到手机；
- 支持为每个自动化任务配置独立工作空间；无头模式下支持 `--task-name` 指定任务名称；

### MCP 与技能生态接入

- 增加 MCP Registry 接入，可直接在桌面端从 OpenHarmony Matrix 和 ModelScope 安装 MCP 服务；通过 stdio 运行的本地 MCP Server 支持独立环境变量管理；
- 技能中心新增内置技能界面，支持技能启用/禁用、批量导入和自动化测试；
- 支持在桌面端和命令行中使用 OpenDesk 提供的技能依赖分析和自动化测试等一系列优化工具；

### 模型与搜索配置

- 支持在设置界面手动设置模型上下文窗口大小，方便对非公开命名模型进行自动上下文压缩；重构上下文自动检测，补全最新模型数据并为未知模型添加 128K 兜底策略；
- 模型配置支持自定义 HTTP 请求头 (headers)；新增 Nvidia NIM 和华为云 MaaS 支持；新增 Ark Agent Plan 到 providers 列表；增加模型分类，聊天模型和嵌入模型使用不同校验策略；
- 新增全局网络配置选项，可自由选择继承全局代理/自定义代理，支持全局配置跳过 SSL 证书校验；
- 支持在设置界面配置环境变量，在所有 Shell 工具调用中自动生效；
- 重构搜索引擎系统，支持图形化配置搜索引擎，新增免费的百度搜索和 DBLP 论文搜索；

### 桌面端体验提升

- 支持感知系统颜色主题，自适应深色模式；
- 新增个人中心界面，支持本地遥测信息收集与展示，展示任务和模型的 token 消耗量统计；
- 支持内连/气泡两种推理块展示模式，模型的思考/推理过程以气泡形式展示，支持折叠与展开；
- 新增斜杠快速命令机制，输入 `/` 即可快速触发命令；
- 增加内置笔记应用，支持富文本编辑和 Agent 自动操作；
- 支持将应用以独立窗口形式打开（右键应用图标）；支持可切换的左侧侧边栏，折叠时保留窄边栏作为快速入口；
- 编辑器从 Monaco 迁移至 Ace，修复字体渲染和宽度计算问题；工具调用中可点击文件类工具直接跳转到编辑器对应位置；
- 支持 Magic Pointer，按下 Alt 用鼠标或触屏在屏幕上勾选内容与 Agent 后续对话；
- 在模型支持多模态时可直接粘贴图片到输入框；
- 在工作空间中点击预览 HTML 网页；

### 鸿蒙平台适配

- 在鸿蒙 PC 上支持语音输入，使用鸿蒙端侧 ASR 能力；
- 使用鸿蒙黑体作为全平台默认字体；禁用 NodeJS 的 JIT 以避免安全策略导致崩溃；
- 在 HarmonyOS 设备上使用 `.opendesk-tmp` 作为专有临时目录，避免污染用户家目录；

### 其他

修复了从 0.2.0 以来的一系列琐碎的问题，在此不一一列举。非常感谢大家的积极反馈 ;)

## 如何升级

对于 Cli 版本，请运行 `npm install -g "@bitclub.ai/opendesk-cli"` 即可将当前 opendesk 升级到最新的稳定版本，或者进入 opendesk 之后，输入 `/upgrade` 命令并选择升级到 Stable(稳定版本) 确认即可。桌面端可直接在 [这里](/download/) 下载。
