OpenDesk 插件可以扩展 Tool、Hook、Skill、MCP Server、Command、应用事件处理和子 Agent 能力。

## 管理插件

可以通过桌面版“插件中心”管理插件，也可以使用 CLI：

~~~bash
opendesk plugins install <本地目录、ZIP、TGZ、URL 或 npm spec>
opendesk plugins list
opendesk plugins enable <插件ID>
opendesk plugins disable <插件ID>
opendesk plugins uninstall <插件ID>
~~~

插件代码在 OpenDesk 主进程中运行。安装或启用第三方插件前，应确认来源可信，并检查其文件、网络、进程和凭据访问行为。

## 开发插件

需要创建自己的插件时，请阅读[插件开发指南](/docs/dev/plugins/)。指南从[插件结构概述](/docs/dev/plugins/)开始，并分章节讲解 Tool、MCP、Skills、钩子、自定义命令，以及调试与发布。
